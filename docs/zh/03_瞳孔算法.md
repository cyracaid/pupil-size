四个阶段，顺序固定：

```
原始样本 ──(1) 判定有效──> 有效掩码 ──(2) 伪影滤波──> 更干净的有效掩码
         ──(3) 插值 + 低通──> 1000 Hz 平滑信号
         ──(4) 分段 + 汇总──> kret_results.csv
```

## 阶段 1–2 · 什么算“有效样本”

`rawDataFilter.m`（主函数在第 1 行）只返回一个逻辑向量：哪些原始样本算有效。下游全部基于它，**被它否掉的样本再也回不来**。

| 步 | 函数（行号） | 剔除什么 | 参数 |
|---|---|---|---|
| 1 | `removeOutOfBounds`（197） | 直径超出 `[Min, Max]` | 默认 1.5 / 9（**毫米**），我们用数据定的像素范围覆盖 |
| 2 | `madSpeedFilter`（229） | 眨眼：相邻样本速度超过 `median + n·MAD` | 16 MAD、最大间隔 200 ms（89、93） |
| 2b | `expandGaps`（511） | 眨眼边缘：宽于 75 ms 的缺口前后各 50 ms | 75–2000 ms、padding 50/50（104–110） |
| 3 | `madDeviationFilter`（284） | 偏离平滑趋势线的点，偏差 > `median + 16·MAD` | 16 MAD（131） |
| 3b | `removeLoners`（440） | 时间上孤立的样本（<50 ms 的孤岛，间隔 >40 ms） | 40 / 50 ms（76、82） |

两个要点：

- 趋势线是“插值后的有效样本 → 16 Hz 低通 → 平均”，并且**回扫 4 趟**（`residualsFilter_passes = 4`，125 行）。回扫的作用是给那些被坏邻居拖偏了趋势线、从而被误删的好样本一个复活的机会。
- 所有阈值都是 `median + n×MAD`，不是均值 ± SD：少数巨大的伪影会把 SD 撑大，反而把自己藏起来。

## 阶段 3 · 从有效样本到平滑信号

`ValidSamplesModel.interpAndSmooth`（107 行），三步：

1. **插值**：有效样本线性插到 1000 Hz 的规则网格（136–142 行；`interp_upsamplingFreq = 1000`，374 行）。
2. **低通**：4 阶 Butterworth，截止 4 Hz，正反各滤一次（`filtfilt`，零相位，峰不会被时间平移）（383–389、193 行）。
3. **长缺口重新标为缺失**：插值跨度超过 `interp_maxGap = 250` ms 的段落，重新置 NaN（193 行，参数在 392 行）。这就是为什么曲线看着连续、`SmoothSig_meanDiam` 却可能是 NaN；也是为什么 100 ms 的眨眼在均值里看不出来、300 ms 的就能看出来。

1000 Hz 是网格，不是新信息：记录本身约 60 Hz，曲线是插出来的，时间分辨率仍是约 17 ms。

## 阶段 4 · 分段与汇总

`PupilDataModel.analyzeSegments`（390）→ `ValidSamplesModel.analyze`（203）。段本身定义在 `csv2kretmat.m` 185–220 行：`baseline` = cue 前 0.5 s，`countdown` = cue → outcome，`preOutcome` = outcome 前 2 s，`postOutcome` = outcome 后 2 s。`analyze` 按段填 12 个统计量——定义见 [列字典 §B](../zh/02_列字典.md)。

代码里给每列设了描述（`Properties.VariableDescriptions`，280 行），但 `writetable` 会丢掉它们——所以列字典必须单独存在。

## 我们实际用的参数

| 参数 | 值 | 谁定的 |
|---|---|---|
| Range filter | 数据驱动的像素范围（0.5–99.5 百分位 × 0.8 / 1.2） | `example_kret_pipeline.m:85–93` |
| 速度滤波 | 16 MAD、200 ms 最大间隔 | 论文默认 |
| 眨眼边缘 | 75–2000 ms 缺口、50 ms padding | 论文默认 |
| 趋势滤波 | 16 MAD、4 趟、16 Hz 趋势线 | 论文默认 |
| 孤立样本 | 40 / 50 ms | 论文默认 |
| 插值 | 1000 Hz、线性 | 论文默认 |
| 低通 | 4 Hz、4 阶、零相位 | 论文默认 |
| 缺失阈值 | 250 ms | 论文默认 |

只有 Range filter 是改过的，而且必须改：论文的 1.5–9 是毫米，我们的数据是相机像素。

## 这些对数字意味着什么

- **被否的样本就没了。** 下游只能“插过去”，所以剔除很多的段看起来平滑、其实大半是插出来的。看均值之前先看 `SmoothSig_missingDataPercent`。
- **滤波是按“每只眼、整段记录”跑的**，不是按 trial。某三分钟特别糟，会改变整个文件的 MAD 估计，所以 trial 的质量并不独立于整段记录的质量。
- **没有针对 YMTC 调过任何参数。** 全部是 Kret & Sjak-Shie 的默认值；想调就得在桌面 MATLAB 里用 `plotData()` 看原始轨迹，而 `-batch` 模式会跳过这步。
