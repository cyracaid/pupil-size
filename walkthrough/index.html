把一个 `.trk` 文本日志解析成一行一个样本的 CSV。纯 MATLAB，不需要任何工具箱。最重要的设计原则写在注释第 14 行：**只记录、不修补**。

1function [T, report] = trk2csv(trkFile, options)
2%TRK2CSV Convert one MRC eye-tracker .trk log into ONE csv, and record every anomaly.
3% EN: Convert one MRC .trk log into one csv, recording anomalies instead of repairing them.
4% KO: MRC .trk 로그 하나를 csv 하나로 변환하고, 이상치는 고치지 않고 기록만 한다.
5% ZH: 把单个 MRC .trk 日志转成一个 csv；异常只记录，不修补。
6%
7% T = trk2csv('sub119_YMTC_..._0001.trk');
8% [T, report] = trk2csv(trkFile, 'OutFolder', 'out', 'CueDurationSec', 1.0); % 'out' = a folder of your choice
9%
10% One row per eye-tracker sample. Task events (SoftwareEvent lines) are not written as
11% rows of their own: each event is attached to the first sample whose timestamp is >= the
12% event time and appears in the `event` column (several events on one sample are joined
13% with ';'). run / trial / trial_in_run / phase are filled forward from the events.
14% NOTHING IS REPAIRED OR INFERRED: if the log deviates from the expected structure
15% (missing START, no events, unexpected counts, cue duration not equal to the setting, ...)
16% the deviation is recorded in report.issues and printed; the data are written as logged.

给 R 读者：两个输出：数据表 T 和一份 report（结构体，含 summary / issues / header / csv）。

第 10–13 行说明了这张表的样子：一行一个样本，事件不单独占行，而是挂到“时间戳第一个大于等于事件时刻”的那个样本上；一个样本上如果有多个事件，用 ; 连起来。run / trial / phase 这些列是从事件往后填的。

第 14–16 行是全文件最重要的约定：日志缺 START、没有事件、cue 时长和设定不符——一律记进 report.issues 并打印，但写出去的数据保持原样。这样下游看到的永远是真实的采集结果，而不是被脚本悄悄“修好”的样子。

93%% ---- Welch t on two samples, base MATLAB (no Statistics Toolbox) ----
94function [t, p, d] = welch(x, y)
95x = x(~isnan(x)); y = y(~isnan(y));
96nx = numel(x); ny = numel(y);
97if nx < 2 || ny < 2, t = NaN; p = NaN; d = NaN; return; end
98 
99mx = mean(x); my = mean(y);
100vx = var(x); vy = var(y);
101se = sqrt(vx/nx + vy/ny);
102t = (mx - my) / se;
103 
104% Welch-Satterthwaite degrees of freedom
105df = (vx/nx + vy/ny)^2 / ((vx/nx)^2/(nx-1) + (vy/ny)^2/(ny-1));
106 
107% two-sided p from the incomplete beta function (base MATLAB)
108p = betainc(df / (df + t^2), df/2, 0.5);
109 
110% Cohen's d with the pooled SD
111sp = sqrt(((nx-1)*vx + (ny-1)*vy) / (nx + ny - 2));
112d = (mx - my) / sp;

127 % Generate the upsampled time vector (seconds):
128 t_upsampled = ...
129 (valid_t_ms(1)/1000 ...
130 :(1/obj.settings.interp_upsamplingFreq)...

141 % Calculate the gaps (the edges dont really matter, samples
142 % close to the edges wil be given a gap of 0 subsequently).
143 % NOTE: for backwards compatibility, histc is used in lieu of
144 % discretize. With newer MATLAB, you could instead use:
145 % gaps_msB = discretize(t_upsampled.*1000 ...
146 % ,valid_t_ms,diff(valid_t_ms));
147 valz = [diff(valid_t_ms);NaN];
148 valz(end) = valz(end-1);
149 % Guard against floating-point overshoot producing bin 0, which
150 % crashes valz(binzIndxA) (upstream issue #4; PsPM fixed the
151 % same bug in bachlab/PsPM#365): clamp query times into the
152 % valid sample range and warn if more than epsilon had to move.
153 tQuery_ms = t_upsampled.*1000;
154 nClamp = sum(tQuery_ms < valid_t_ms(1)) ...
155 + sum(tQuery_ms > valid_t_ms(end));
156 if nClamp > 0
157 warning('pupilSize:edgeClamp', ...
158 ['%i upsampled time(s) (%.4f%%) fell outside the valid' ...
159 ' sample range and were clamped to the nearest edge.'], ...
160 nClamp, 100*nClamp/numel(tQuery_ms));
161 end
162 tQuery_ms = min(max(tQuery_ms, valid_t_ms(1))...
163 ,valid_t_ms(end));
164 [~,binzIndxA] = histc(tQuery_ms, valid_t_ms);
165 gaps_ms = valz(binzIndxA);
166
167 % Set samples that are really close to the raw samples as
168 % having no gap (scale the closeness with the sampling freq.).
169 % In this case it is set to half the sampling interval:
170 notTouchingYouTolerance_ms = (0.5*1000)...
171 /obj.settings.interp_upsamplingFreq;
172
173 % NOTE: The command histc is used for backwards compatibility,
174 % in MATLAB 2015a and newer you could instead use:
175 % almostTouching = ismembertol(t_upsampled.*1000,valid_t_ms...
176 % ,notTouchingYouTolerance_ms,'DataScale',1);
177 %
178 % Generate edges using the timestamps of the valid samples, +/-
179 % the tolerance and use histc to place the upsampled timestamps
180 % in the bins. Since MATLAB generates bins between all edges,
181 % test only for even-bins hit. Those hits will signify that a
182 % upsampled timestamp was within the tolerance of a valid
183 % measured datapoint:
184 binz = bsxfun(@plus ...
185 ,valid_t_ms,[-1 1] .* notTouchingYouTolerance_ms)';
186 [~,binHits] = histc(t_upsampled.*1000 ...
187 , binz(:));
188 almostTouching = mod(binHits,2);

190 % Now actually set the upsampled timestamps that are really
191 % close to the timestamps of the valid measured datapoints to

195 % Remove gaps:
